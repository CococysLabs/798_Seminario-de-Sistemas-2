Proyecto 2 - Ejercicio guiado: análisis exploratorio y modelo lineal con BigQuery ML

Se publica un ejercicio guiado basado en el dataset público bigquery-public-data.new_york_taxi_trips.tlc_yellow_trips_2022. El objetivo es practicar un flujo mínimo pero técnicamente correcto que cubra: exploración inicial, creación de una tabla derivada optimizada, construcción de un conjunto de variables y entrenamiento de un modelo lineal de regresión en BigQuery ML.

Objetivo del ejercicio

Construir un modelo de regresión lineal que estime tip_amount a partir de variables del viaje, y comprender la relación entre:

  • dataset fuente;
  • limpieza y transformación de datos;
  • feature engineering;
  • definición de variable objetivo;
  • entrenamiento y evaluación de un modelo predictivo.

Paso 1. Explorar el esquema del dataset

Antes de entrenar cualquier modelo, debe entenderse qué columnas existen, cuáles son numéricas, cuáles son categóricas y qué variable objetivo se desea predecir. 

SELECT
  column_name,
  data_type,
  is_nullable,
  ordinal_position
FROM `bigquery-public-data.new_york_taxi_trips.INFORMATION_SCHEMA.COLUMNS`
WHERE table_name = 'tlc_yellow_trips_2022'
ORDER BY ordinal_position;

Paso 2. Realizar una exploración inicial

Validar volumen, rango temporal y algunos patrones básicos del dataset antes de transformarlo. 

SELECT
  COUNT(*) AS total_rows,
  MIN(pickup_datetime) AS min_pickup_datetime,
  MAX(pickup_datetime) AS max_pickup_datetime,
  MIN(trip_distance) AS min_trip_distance,
  MAX(trip_distance) AS max_trip_distance
FROM `bigquery-public-data.new_york_taxi_trips.tlc_yellow_trips_2022`;

SELECT
  EXTRACT(MONTH FROM pickup_datetime) AS pickup_month,
  COUNT(*) AS trips,
  ROUND(AVG(total_amount), 2) AS avg_total_amount,
  ROUND(AVG(trip_distance), 2) AS avg_trip_distance
FROM `bigquery-public-data.new_york_taxi_trips.tlc_yellow_trips_2022`
GROUP BY pickup_month
ORDER BY pickup_month;

Paso 3. Crear el dataset de trabajo

CREATE SCHEMA IF NOT EXISTS `project-9f4fe3c2-3919-4941-805.proyecto2_taxi`
OPTIONS (
  location = 'US',
  description = 'Proyecto 2 Seminario de Sistemas 2 - NYC Taxi Trips 2022'
);

Paso 4. Crear una tabla derivada optimizada

La tabla optimizada permite controlar mejor el costo de análisis y preparar una base más limpia para machine learning. Se particiona por pickup_date y se clusteriza por variables utilizadas con frecuencia en análisis y segmentación. 

DECLARE source_start_date DATE DEFAULT DATE '2022-01-01';
DECLARE source_end_date DATE DEFAULT DATE '2022-12-31';

CREATE OR REPLACE TABLE `project-9f4fe3c2-3919-4941-805.proyecto2_taxi.taxi_trips_2022_optimized`
PARTITION BY pickup_date
CLUSTER BY vendor_id, pickup_location_id, dropoff_location_id, payment_type
AS
WITH source_data AS (
  SELECT
    vendor_id,
    pickup_datetime,
    dropoff_datetime,
    DATE(pickup_datetime) AS pickup_date,
    passenger_count,
    trip_distance,
    rate_code,
    store_and_fwd_flag,
    pickup_location_id,
    dropoff_location_id,
    payment_type,
    fare_amount,
    extra,
    mta_tax,
    tip_amount,
    tolls_amount,
    imp_surcharge,
    airport_fee,
    total_amount
  FROM `bigquery-public-data.new_york_taxi_trips.tlc_yellow_trips_2022`
  WHERE DATE(pickup_datetime) BETWEEN source_start_date AND source_end_date
)
SELECT
  vendor_id,
  pickup_datetime,
  dropoff_datetime,
  pickup_date,
  passenger_count,
  trip_distance,
  rate_code,
  store_and_fwd_flag,
  pickup_location_id,
  dropoff_location_id,
  payment_type,
  fare_amount,
  extra,
  mta_tax,
  tip_amount,
  tolls_amount,
  imp_surcharge,
  airport_fee,
  total_amount,
  TIMESTAMP_DIFF(dropoff_datetime, pickup_datetime, MINUTE) AS trip_duration_minutes,
  EXTRACT(HOUR FROM pickup_datetime) AS pickup_hour,
  EXTRACT(DAYOFWEEK FROM pickup_datetime) AS pickup_day_of_week,
  EXTRACT(MONTH FROM pickup_datetime) AS pickup_month,
  SAFE_DIVIDE(tip_amount, NULLIF(fare_amount, 0)) AS tip_pct,
  IF(SAFE_DIVIDE(tip_amount, NULLIF(fare_amount, 0)) >= 0.20, 1, 0) AS is_high_tip
FROM source_data
WHERE pickup_datetime IS NOT NULL
  AND dropoff_datetime IS NOT NULL
  AND dropoff_datetime >= pickup_datetime
  AND passenger_count BETWEEN 1 AND 6
  AND trip_distance > 0
  AND trip_distance <= 100
  AND fare_amount > 0
  AND fare_amount <= 500
  AND tip_amount >= 0
  AND total_amount > 0
  AND total_amount <= 1000;

Paso 5. Construir la tabla de features

En esta etapa se define qué filas se usarán para entrenamiento, evaluación y predicción. Esto ayuda a evitar fuga de información y permite una separación temporal del problema. 

CREATE OR REPLACE TABLE `project-9f4fe3c2-3919-4941-805.proyecto2_taxi.ml_features_taxi_2022`
PARTITION BY pickup_date
CLUSTER BY split_col, payment_type, vendor_id, pickup_location_id, dropoff_location_id
AS
SELECT
  pickup_date,
  vendor_id,
  passenger_count,
  trip_distance,
  rate_code,
  store_and_fwd_flag,
  pickup_location_id,
  dropoff_location_id,
  payment_type,
  fare_amount,
  trip_duration_minutes,
  pickup_hour,
  pickup_day_of_week,
  pickup_month,
  is_high_tip,
  tip_amount,
  CASE
    WHEN pickup_date < '2022-10-01' THEN 'TRAIN'
    WHEN pickup_date < '2022-12-01' THEN 'EVAL'
    ELSE 'PREDICT'
  END AS split_col
FROM `project-9f4fe3c2-3919-4941-805.proyecto2_taxi.taxi_trips_2022_optimized`
WHERE trip_duration_minutes BETWEEN 1 AND 180
  AND tip_amount BETWEEN 0 AND 200
  AND fare_amount BETWEEN 1 AND 300;

Paso 6. Entrenar un modelo lineal de regresión

El objetivo será predecir tip_amount. En este punto, las columnas del SELECT son las variables que se le pasan al modelo para aprender, mientras que tip_amount es la variable objetivo. 

CREATE OR REPLACE MODEL `project-9f4fe3c2-3919-4941-805.proyecto2_taxi.modelo_regresion_propina_lineal`
OPTIONS (
  model_type = 'LINEAR_REG',
  input_label_cols = ['tip_amount'],
  l2_reg = 1.0
) AS
SELECT
  vendor_id,
  passenger_count,
  trip_distance,
  rate_code,
  store_and_fwd_flag,
  pickup_location_id,
  dropoff_location_id,
  payment_type,
  fare_amount,
  trip_duration_minutes,
  pickup_hour,
  pickup_day_of_week,
  pickup_month,
  tip_amount
FROM `project-9f4fe3c2-3919-4941-805.proyecto2_taxi.ml_features_taxi_2022`
WHERE split_col = 'TRAIN';

Paso 7. Evaluar el modelo lineal

Para la evaluación se usa el conjunto EVAL. Las métricas esperadas incluyen mean_absolute_error, mean_squared_error y r2_score. A partir de mean_squared_error también puede obtenerse RMSE. 

SELECT *
FROM ML.EVALUATE(
  MODEL `project-9f4fe3c2-3919-4941-805.proyecto2_taxi.modelo_regresion_propina_lineal`,
  (
    SELECT
      vendor_id,
      passenger_count,
      trip_distance,
      rate_code,
      store_and_fwd_flag,
      pickup_location_id,
      dropoff_location_id,
      payment_type,
      fare_amount,
      trip_duration_minutes,
      pickup_hour,
      pickup_day_of_week,
      pickup_month,
      tip_amount
    FROM `project-9f4fe3c2-3919-4941-805.proyecto2_taxi.ml_features_taxi_2022`
    WHERE split_col = 'EVAL'
  )
);

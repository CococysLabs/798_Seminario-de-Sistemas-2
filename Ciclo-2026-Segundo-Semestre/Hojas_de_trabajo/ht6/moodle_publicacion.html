Hoja de Trabajo 6 - Modelo de clasificacion con BigQuery ML

En esta hoja de trabajo se construira un modelo de clasificacion binaria usando el dataset de taxis trabajado en el Proyecto 2. El objetivo es predecir si un viaje tendra propina alta.

Objetivo

  • Preparar una tabla de features para clasificacion.
  • Entrenar un modelo LOGISTIC_REG con BigQuery ML.
  • Evaluar el modelo con al menos una metrica de clasificacion.
  • Mostrar la matriz de confusion con ML.CONFUSION_MATRIX.
  • Interpretar brevemente los resultados.

Dataset

Se debe trabajar con el dataset de taxi_trips_2022

La etiqueta del modelo sera is_high_tip, donde 1 representa propina alta y 0 representa no propina alta.

Regla para la etiqueta

IF(SAFE_DIVIDE(tip_amount, NULLIF(fare_amount, 0)) >= 0.20, 1, 0) AS is_high_tip

Instrucciones

  1. Reemplazar TU_PROYECTO por el ID real del proyecto.
  2. Crear o verificar una tabla de features para clasificacion.
  3. Dividir los datos en TRAIN, EVAL y PREDICT.
  4. Entrenar un modelo LOGISTIC_REG.
  5. Ejecutar ML.EVALUATE.
  6. Reportar al menos una metrica: precision, recall, f1_score, accuracy 
  7. Ejecutar ML.CONFUSION_MATRIX.
  8. Explicar que significa un falso positivo y un falso negativo.

Entregable

Un archivo PDF con:

  • Script SQL final.
  • Resultado o captura de ML.EVALUATE.
  • Resultado o captura de ML.CONFUSION_MATRIX.
  • Explicacion breve de una metrica de clasificacion precision, recall, f1_score, accuracy 
  • Respuesta: ¿Que significa un falso negativo en este problema?

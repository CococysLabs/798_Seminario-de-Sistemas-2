# Checklist de clase

## Antes de clase

- [ ] Proyecto GCP creado.
- [ ] APIs habilitadas.
- [ ] Terraform aplicado.
- [ ] Secretos de Codespaces configurados.
- [ ] Codespace docente probado.
- [ ] `dbt debug` exitoso.
- [ ] `dbt seed` exitoso.
- [ ] `dbt run` exitoso.
- [ ] `dbt test` exitoso.
- [ ] dbt Docs visible en puerto 8080.

## Durante clase

- [ ] Explicar raw, staging, intermediate y marts.
- [ ] Mostrar `source()`.
- [ ] Mostrar `ref()`.
- [ ] Mostrar una macro simple.
- [ ] Ejecutar pruebas.
- [ ] Provocar una prueba fallida.
- [ ] Revisar linaje en dbt Docs.
- [ ] Consultar marts en BigQuery.

## Despues de clase

- [ ] Eliminar datasets de grupos si aplica.
- [ ] Rotar o borrar llave de service account.
- [ ] Revisar costos de BigQuery/GCS.
- [ ] Apagar o destruir VM si se activo.

# Nomenclatura del material

Código del curso: `798`. Período: `2S2026`.

| Recurso | Patrón |
|---|---|
| Proyecto | `798_Proyecto_#_2S2026` |
| Práctica | `798_Practica_#_2S2026` |
| Tarea | `798_Tarea_#_2S2026` |
| Presentación | `798_Presentacion_S#_2S2026` |
| Lectura | `798_Lectura_#_2S2026` |
| Ejemplo demostrativo descargable | `798_Ejemplo_#_2S2026` |
| Video | `798_Video_#_2S2026` |
| Hoja de trabajo / actividad práctica | `798_ActividadPractica_#_2S2026` |
| Diagnóstico | `798_Diagnostico_2S2026` |
| Tarea de fortalecimiento | `798_TFortalecimiento_2S2026` |

Se conserva la extensión correspondiente. En presentaciones y lecturas, el número identifica la semana actual de destino. Los recursos adicionales de la misma semana conservan su título en subcarpetas, sin añadir sufijos al patrón. Las rúbricas se identifican mediante su carpeta `Rubrica`.

Los ejemplos descargables (ZIP y notebooks) se numeran dentro de su semana o actividad. El código fuente, los datasets, las bibliografías, los README y los nombres internos de los proyectos mantienen sus nombres técnicos para conservar su funcionamiento. Las fuentes LaTeX de las lecturas comparten el nombre del PDF.

El programa y el examen en Markdown conservan su nombre: la nomenclatura suministrada no define una categoría para ellos. No se incorporan recursos nuevos de diagnóstico ni videos en este cambio.
